## 复习建议

1. 先从能量流向理解电磁转矩、感应电动势和功率平衡，再把公式中的量对应到电机结构。
2. 统一转速、角速度、转矩的正方向与单位，分析负载特性和运行点后再代入计算。
3. 把串电阻、调电枢电压、弱磁调速放在同一张机械特性图上比较，说明适用范围和局限。
4. 把起动、调速、制动各做一道完整计算与作图题，并从运动方程追踪暂态到稳态。
5. 把 51–56 讲义按“绕组与磁势 → 旋转磁场 → 等值电路和功率 → 转矩 → 参数测定”串起来，区分空间角度、电角度与时间相位。

更详细的版本说明与使用建议见 [课程 README](https://github.com/AIAADC/Fundamentals-of-Electric-Machines-and-Drives#readme)。
