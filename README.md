## 🧭 按学习阶段使用

| 阶段 | 建议做法 | 要留下的成果 |
| --- | --- | --- |
| 课前预习 | 浏览当节课件标题与核心概念，记下已有知识和疑问 | 一张概念草图、几个具体问题 |
| 课后整理 | 独立复现公式推导、时序图或系统框图，再对照课件 | 能说清前提、符号和每一步的笔记 |
| 阶段复习 | 先默写知识框架，再按错因补计算、作图与概念辨析 | 分章节的薄弱点清单 |
| 课程实践 | 先理解原理与接口，再完成自己的操作、记录和分析 | 可以解释现象与误差的原始记录 |

## 🔗 把几门课串起来

- **电路与信号基础 → 传感技术**：用电桥、放大与动态响应理解传感器怎样把物理量变成电信号。
- **自控（一） → 自控（二）**：从连续系统走向采样、Z 变换与离散控制，比较稳定区域与性能分析方法。
- **电机拖动 ↔ 自动控制**：用运动方程和机械特性建立对象模型，再理解控制要求从何而来。
- **微机原理 → 测量与控制实现**：用存储器、I/O 接口和 8255A 理解程序如何连接外部硬件。
- **计算机网络 → 系统通信**：以分层、寻址和可靠传输解释数据如何跨设备流动。
- **模式识别与机器学习 → 数据分析**：把线性代数、概率统计与优化连接到分类、特征提取和聚类方法。
