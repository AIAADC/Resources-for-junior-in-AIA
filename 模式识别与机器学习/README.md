## 复习建议

1. 先用同一组二维样本比较感知器、线性回归、Fisher判别和Logistic回归，逐一写清模型输出、目标函数、优化方式及分类边界，避免只记公式。
2. 沿“最大间隔—约束优化—拉格朗日对偶—核函数”的顺序复习SVM，并区分一对多、一对一与Softmax多类分类策略。
3. 复习神经网络时按前向传播、损失函数、反向传播和参数更新串成流程；CNN部分画出特征图尺寸和卷积核作用，再连接具体应用。
4. 将Bagging、AdaBoost、决策树和随机森林放在同一张比较表中；统计决策部分分清最小错误率与最小风险，再衔接参数估计、近邻估计和Parzen窗法。
5. 区分特征选择与特征提取，亲手完成一个小矩阵的PCA步骤；聚类部分比较距离度量、层次聚类与K均值的目标及迭代过程。

更详细的版本说明与使用建议见 [课程 README](https://github.com/AIAADC/Pattern-Recognition-and-Machine-Learning#readme)。
