## 复习建议

1. 先用采样周期T和映射z=exp(sT)连接连续系统与离散系统，理解混叠和零阶保持的作用。
2. 把Z变换、逆Z变换和差分方程互相转换；每道题写清楚初始条件和采样位置。
3. 建立脉冲传递函数时先标出采样开关与保持器，再判断各环节能否直接相乘。
4. 按稳定性、动态响应、稳态误差三个步骤分析系统，记住离散稳定区域在z平面的单位圆内。
5. 最少拍控制先确定输入类型与误差要求，再检查因果性、稳定性、可实现性以及是否要求无纹波。
6. 相平面法先辨认状态变量与奇点，再画轨迹和方向；将局部轨迹特征与稳定性对应起来。
7. 状态空间建模先选状态变量，再列状态方程和输出方程；用电路或机械系统检查状态维数、单位和矩阵尺寸。

更详细的版本说明与使用建议见 [课程 README](https://github.com/AIAADC/Principles-of-Automatic-Control-#readme)。
