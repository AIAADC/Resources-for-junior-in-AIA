## 复习建议

1. 先画清楚分层、封装、端到端与逐跳传输的关系，再把每层协议放回图中。
2. 物理层重点区分比特率与波特率，分别练习奈奎斯特与香农公式，留意信噪比的dB换算。
3. 链路层用时序图练习停等、滑动窗口与可靠传输；CRC按位演算一遍，局域网比较CSMA/CD与CSMA/CA。
4. 网络层分别练习路由算法、IPv4地址与子网、分片；明确转发与路由、MAC地址与IP地址的区别。
5. 传输层结合双语第6章比较TCP/UDP，串起可靠传输、流量控制与拥塞控制；术语和公式以原文及当前课堂要求核对。

更详细的版本说明与使用建议见 [课程 README](https://github.com/AIAADC/Computer-Networks#readme)。
