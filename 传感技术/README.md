## 复习建议

1. 先画测量链：被测量、敏感元件、转换元件、测量电路、输出信号各负责什么，能用一个传感器实例解释清楚。
2. 把量程、灵敏度、线性度、迟滞、重复性和分辨力放在同一张对照表里，分别说明定义、单位和误差含义。
3. 动态特性回到一阶、二阶模型：把时间常数、频率响应与测量速度联系起来，判断输入变化能否被准确跟随。
4. 应变式传感器沿“应力/应变 → 电阻变化 → 电桥输出”推导；比较金属应变效应和半导体压阻效应。
5. 结合实验课件比较单臂、半桥、全桥的接法与灵敏度，再整理差动变压器、电容、霍尔、电涡流和光纤的位移测量原理。
